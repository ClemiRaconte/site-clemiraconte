METTRE EN LIGNE — DEUX OPTIONS
------------------------------
OPTION A — Hébergement OVH (inclus avec le domaine)
1. Activer l'hébergement gratuit dans l'espace client OVH
2. Téléverser le CONTENU de ce dossier (pas le dossier lui-même)
   via le gestionnaire de fichiers OVH ou un logiciel FTP (FileZilla)
3. Le domaine clemiraconte.fr est déjà chez OVH : raccordement quasi
   automatique
⚠ Le formulaire de contact actuel est prévu pour Netlify : sur OVH,
   il faudra le rebrancher (solution simple type Formspree, ou
   formulaire Brevo) — à faire avec Claude au moment de la mise en ligne.

OPTION B — Netlify (gratuit aussi)
1. Créer un compte sur netlify.com
2. Glisser-déposer CE DOSSIER ENTIER sur le tableau de bord
3. Relier le domaine : Site settings > Domain management > Add custom
   domain > clemiraconte.fr (entrées DNS à ajouter chez OVH, comme
   pour Brevo)
4. Le formulaire de contact fonctionne tout seul (onglet "Forms")

Dans les deux cas, le certificat HTTPS est automatique et gratuit.
Le formulaire ne fonctionne jamais en local : c'est normal.

LA SÉANCE VITRINE (interchangeable)
-----------------------------------
La séance offerte en téléchargement est actuellement "Ange, le loup
qui chantait avec le vent". Pour la remplacer un jour par une autre :
1. Déposer les 3 nouveaux PDF dans assets/pdf/
2. Mettre à jour les liens et textes à DEUX endroits :
   - mallette.html, section "Jugez sur pièce"
   - la page de l'histoire concernée
3. Mettre à jour la section "La séance vitrine" de index.html
(Demander à Claude : "remplace la séance vitrine par [titre]" suffit.)

AJOUTER UNE NOUVELLE HISTOIRE
-----------------------------
1. Dupliquer histoire-ange-le-loup.html, renommer
   (ex: histoire-le-tablier-vert.html — garder ce format d'adresse,
   c'est lui qui sera imprimé dans les QR codes : NE PLUS LE CHANGER ENSUITE)
2. Modifier le titre, le bloc, l'âge et le texte de présentation
3. Quand la vidéo YouTube est en ligne : suivre les instructions en
   commentaire dans le fichier (remplacer le bloc "lecteur-attente"
   par l'iframe YouTube avec le bon ID)
4. Même chose pour le podcast Ausha (commentaire dans le fichier)
5. Ajouter la carte correspondante dans histoires.html
   (copier-coller une carte existante et adapter)

NOTES TECHNIQUES
----------------
- Aucune dépendance, aucun framework : HTML + CSS purs, modifiables
  par n'importe quel développeur.
- Polices chargées depuis Google Fonts (Fraunces, Source Sans 3, Caveat).
- Couleurs de marque dans assets/styles.css (variables en haut du
  fichier) : --sapin #2D6A4F, --soleil #F4C430.
- Les vidéos utilisent youtube-nocookie.com (moins de cookies déposés).
